Teacher's Lesson Plan Architect
Our project is an AI-powered Teacher’s Lesson Plan Architect that generates structured classroom presentations instantly.
It creates slide-based lesson plans with integrated quizzes using OpenAI API.
The system helps teachers save time, improve engagement, and deliver organized 40-minute lessons efficiently.

Tech Stack: 
Frontend: Streamlit
Backend: Python
Database: MySQL
AI Integration: OpenAI API
Authentication: Session-based login
Tools: Git, GitHub, VS Code
